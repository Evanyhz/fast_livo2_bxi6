# 1.部署fast_livo2：
```bash
  mkdir -p ~/fast_livo2_bxi6    #新建文件夹
  cd fast_livo2_bxi6
  git clone https://github.com/Evanyhz/fast_livo2_bxi6
  mv fast_livo2_bxi6 src       #把克隆过来的的文件夹重命名为src
  #然后按照clone文件夹的 readme3.md 进行部署
```
